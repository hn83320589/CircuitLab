# 從需求到上線：以 CircuitLab Jr. 學程式設計與系統分析

這是一份以真實專案為案例的教學文件。案例是 **CircuitLab Jr.**，一個給國中理化課使用的直流電路模擬網頁。我們會從「客戶丟來一段需求」開始，一路走過需求分析、系統分析、架構設計、技術選型、寫程式、設計演算法、測試，最後部署上線並通過驗收。

這個案例適合教學，原因是它**夠小又夠完整**：

- 規模約 3,000 行 TypeScript，一個人幾天可以讀完。
- 需求裡有明確的驗收標準，可以練習「把需求寫成測試」。
- 核心是一個真正的數值演算法（電路求解），不是單純的增刪改查。
- 有大量「錯誤輸入」要處理（學生會亂接電路），很適合練習防禦式設計。
- 開發過程中真的踩過坑，第 8 章完整記錄了發現問題、找原因、修正的過程。

## 先備知識

- **程式**：會寫 JavaScript；看過 TypeScript 的型別標註更好。React 只需要知道 component、props、state 的概念。
- **數學**：國中理化的歐姆定律、串聯與並聯。第 6 章會用到矩陣與聯立方程式（高一程度），文件中會從頭推導。
- **工具**：會用終端機執行 `npm` 指令，會用 Git 的基本操作。

## 動手準備

```bash
git clone https://github.com/hn83320589/CircuitLab.git
cd CircuitLab
npm install
npm run dev      # 開啟 http://localhost:5173
npm test         # 執行 123 個單元測試與性質測試
```

建議一邊讀一邊打開對應的原始碼。文件中提到的檔案都以 `src/...` 的路徑標示。
